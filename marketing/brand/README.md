# Brand assets

Logos and project documents for the marketing films. Built 2026-11-24.
Every logo PNG is transparent, trimmed to the mark with a 3 % margin, and was checked composited on
black and on white (no white fringe). Rebuild all of them with `python3 -I marketing/brand/make-logos.py`.
Files in `source/` and `plans/` are the originals as downloaded from Google Drive, byte for byte
(only renamed to ASCII where noted).

## Which version on which background

| Suffix | Colours | Use on |
|---|---|---|
| `-color.png` | brand colours, as printed | white or light backgrounds |
| `-on-dark.png` | the brand's own dark-ground colours (see each logo) | navy, black, dark photos |
| `-white.png` | all white | dark photos and video; any one-colour need |
